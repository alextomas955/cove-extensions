# Repository instructions

Read and follow [CLAUDE.md](CLAUDE.md) before working in this repository. It is the
canonical repository guidance; keep shared instructions there.

Before working within an extension, also read its `extensions/<Name>/CLAUDE.md`.
Read the files in `.claude/rules/` whose `paths` patterns match the files you touch.
These rules supplement the root guidance and may need to be loaded explicitly by
tools that do not discover Claude instruction files.
