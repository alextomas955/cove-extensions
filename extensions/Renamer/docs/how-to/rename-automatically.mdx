Renamer can keep names up to date for you. With auto-rename on, editing a video's or image's
metadata in Cove renames that item straight away.

## Turn on auto-rename

1. On the Renamer page, go to **Run & automation**.
2. Turn on **Auto-rename on update**.
3. Select **Save changes**.

![The Run and automation card, with the Auto-rename on update switch and the Dry run and Rename all files buttons.](../img/run-automation.jpg)

:::tip[Run a dry run first]
Auto-rename uses the same settings as a manual rename. Run a **Dry run** before you turn it on, so you
know what your template does to your library.
:::

## Good to know

- **Videos and images only.** Audio files and text documents are never renamed automatically.
- **Editing several items at once renames each of them.**
- **One edit, one rename.** A rename also tells Cove the item changed. Renamer ignores that echo, so it
  never renames the same item twice for one edit.
- **An item that already has the right name is left alone.**
